# lassopack

You can get **lassopack** from SSC. 

```
ssc install lassopack
```

Alternatively, you can install the latest _stable_ version of **lassopack** from Github using

```
net install lassopack, ///
from("https://raw.githubusercontent.com/statalasso/lassopack/master/") 

```

The current development version can be installed (at your own risk) as follows:

```
net install lassopack, ///
from("https://raw.githubusercontent.com/statalasso/lassopack/dev/") 
```

For earlier versions, use for example

```
net install lassopack, ///
from("https://raw.githubusercontent.com/statalasso/lassopack/v1.4.3/") 
```

where 1.4.3 is the version number.

For even earlier versions, see https://github.com/statalasso/lassopack/tree/archive.
